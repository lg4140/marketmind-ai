# MarketMind AI v1.2 — 需求访谈、可用性研究与编码模板（尚未执行）

## 研究目的
验证三类核心假设：重复 Notebook 分析是否频繁、可信数值证据是否高价值、研究用户是否愿意让 Agent 自动选择只读工具。明确失败成本和接受 AI 结论的条件。

## 样本计划
- 初级量化研究员 2–3 人；金融数据分析师 2–3 人；研究复核者 1–2 人。
- 招募必须告知“合成数据/非投资建议/可退出”，只记录自愿提供的非敏感任务反馈。
- 不捏造访谈对象、工作背景、原话或问卷结果。

## 访谈提纲（每人 25–35 分钟）
1. 最近一次你分析盘口数据，目标、输入与交付是什么？
2. 你怎样验证时间戳对齐、数据缺失、错误档位？
3. 哪些步骤最耗时？出现错误后如何处理？
4. 如果 Agent 自动调用分析工具，你最想批准或检查哪一步？
5. 你信任一个数值时，需要哪些证据（来源/参数/代码/图表）？
6. 哪些任务适合模板按钮，哪些需要动态工具选择？
7. 查看 Demo：请说出当前任务状态，哪里能找指标来源？
8. 如果质量检查 BLOCK，你希望得到怎样的修复建议？
9. 什么情况下你完全不希望 Agent 自动执行？
10. 对输出格式、交互速度、可控性按重要程度排序。

## 编码规则
- `Workflow Repetition`，`Time Alignment`，`Evidence Need`，`Trust/Autonomy`，`Risk/Fear`，`UI Comprehension`，`Feature Request`。
- 记录匿名 ID、原话摘录（经同意）、问题编码、严重度、出现频次与设计影响。
- 明确区分用户原话、研究员解释和产品方案；用对立证据检验假设。
